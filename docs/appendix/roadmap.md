# 附录 F：90 天迭代路线图

> 本路线图建议 GeoLibre 使用手册随 GeoLibre 版本迭代的手册更新节奏
> 检索日期：2026-07-31

## F.1 迭代原则

1. **跟随版本**：GeoLibre 发布新版本后 2-4 周内更新手册
2. **按需更新**：仅当功能变化影响用户操作时更新对应章节
3. **保持精简**：总字数不超过 5 万字，新增内容需精简旧内容平衡
4. **事实优先**：新功能先标 [待核实]，确认后改为 [已核实]

## F.2 第一阶段：v1.0 完善期（D1-D30）

**目标**：手册 v1.0 正式发布

| 周次 | 任务 | 负责人 |
|------|------|--------|
| W1 | 完成 13 章 + 附录撰写 | 写作型 |
| W2 | 截图采集（50 张） | 工程型 |
| W3 | 录屏制作（3 段） | 工程型 |
| W4 | Docusaurus 站点上线 + Cloudflare Pages 部署 | 工程型 |

**里程碑**：geolibre-manual.pages.dev 上线
