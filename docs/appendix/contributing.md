## E.1 如何贡献

### E.1.1 报告问题

发现手册内容有误或过时？请通过以下方式反馈：

1. 确认错误类型：事实错误、链接失效、描述过时、遗漏功能
2. 提供修正建议和信息源
3. 说明相关 GeoLibre 版本

### E.1.2 提交修订

如果你有修订内容：

1. 遵循本手册的"事实与研判分离"原则
2. 为所有事实声明提供信息源 URL
3. 使用 [已核实]/[待核实]/[推断] 标注
4. 保持术语与术语表一致
5. 遵循 Markdown 格式规范

### E.1.3 新增内容

如需新增章节或大幅扩展：

1. 先确认内容是否适合本手册定位（用户指南，非开发文档）
2. 与现有章节避免重复
3. 遵循章节结构模板
4. 控制单章长度（3000-6000 字）

## E.2 风格规范

### E.2.1 事实标注

所有事实陈述必须标注：

- `[已核实]` — 有明确官方来源，附 URL
- `[待核实]` — 来源单一或存疑
- `[推断]` — 基于现有信息的合理推测

### E.2.2 引用格式

- 首次出现写全称：`GeoLibre 官方文档（URL）`
- 所有 URL 附检索日期：`[检索日期 YYYY-MM-DD]`
- 章节末尾附信息源列表

### E.2.3 术语规范

- 使用术语表中的标准译法
- 英文术语首次出现时附中文翻译
- 专有名词保持原文（MapLibre、DuckDB、GeoParquet 等）

## E.3 质量检查

提交修订前请自检：

- [ ] 所有 `[已核实]` 声明附 URL
- [ ] 无编造的人物、机构、URL、数字
- [ ] 术语使用与术语表一致
- [ ] 章节间交叉引用正确
- [ ] 截图/录屏为真实运行结果（如涉及）
- [ ] 按"小白能否读懂"标准审视
